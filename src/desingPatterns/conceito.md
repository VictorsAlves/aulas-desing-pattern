# Desing Patterns

## O que são Design Patterns?

Design Patterns são soluções reutilizáveis para problemas comuns que surgem durante o desenvolvimento de software. 
Eles são como "receitas" ou "modelos" que os desenvolvedores podem seguir para resolver problemas específicos de design
de software de maneira eficiente e eficaz.

## creational patterns
### singleton
#### quando usar 
 - Quando você quer ter uma instancia unica e compartilhada de uma classe.
 - Gerenciamento de configurações (Config).
 - Conexões com banco de dados ou APIs. 
 - Loggers. 
 - Cache de sistema.

## structural patterns
### composite
#### quando usar
- Quando você quer tratar objetos individuais e composições de objetos de maneira uniforme.
- Estruturas hierárquicas, como árvores ou gráficos.
- Interfaces de usuário, onde componentes podem conter outros componentes.
- Sistemas de arquivos, onde diretórios podem conter arquivos e outros diretórios.
- Processamento de documentos, onde elementos podem conter outros elementos (ex: HTML, XML).
